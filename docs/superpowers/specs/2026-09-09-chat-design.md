# Дизайн-специфікація: Модуль чатів та особистих повідомлень (Direct Messages & Group Chats) у Prostir

## 1. Мета та огляд
Створення підсистеми особистих повідомлень (1-on-1 Direct Messages) та групових чатів у додатку **Prostir** з підтримкою текстових повідомлень і завантаження фотографій у реальному часі через **Convex**.
Результатом завдання є покрокова навчальна інструкція `lesson-10-module-06/docs/16-chat.md` для проведення практичного заняття зі студентами.

---

## 2. Архітектура та модель даних (Convex)

### 2.1. Таблиця `conversations`
Зберігає метадані розмови (особистої або групової):
- `isGroup: v.boolean()` — ознака групи (true — груповий чат, false — особистий діалог).
- `name: v.optional(v.string())` — назва групи (тільки якщо `isGroup === true`).
- `participantIds: v.array(v.id("users"))` — масив ID усіх учасників.
- `creatorId: v.id("users")` — творець чату.
- `lastMessage: v.optional(v.string())` — прев'ю останнього тексту або "📷 Фотографія".
- `lastMessageAt: v.optional(v.number())` — timestamp останньої активності для сортування списку чатів.

### 2.2. Таблиця `messages`
Зберігає окремі повідомлення:
- `conversationId: v.id("conversations")` — прив'язка до розмови.
- `senderId: v.id("users")` — автор повідомлення.
- `content: v.string()` — текстовий вміст повідомлення.
- `imageUrl: v.optional(v.string())` — публічний URL зображення.
- `storageId: v.optional(v.id("_storage"))` — ID фото в Convex Storage.
- `createdAt: v.number()` — мітка часу створення (Date.now()).
- Індекс: `by_conversation` (`["conversationId"]`).

### 2.3. Backend-функції Convex
- **`convex/conversations.ts`**:
  - `getConversations`: повертає всі чати поточного користувача, відсортовані за `lastMessageAt` desc, з підтягуванням інформації про співрозмовника або учасників групи.
  - `getOrCreateDirectConversation`: перевіряє наявність 1-on-1 розмови між поточним користувачем та цільовим. Створює нову або повертає існуючу.
  - `createGroupConversation`: створює нову групу з переданою назвою та списком учасників.
  - `getConversation`: повертає інформацію про конкретний чат та його учасників.
- **`convex/messages.ts`**:
  - `getMessages`: повертає всі повідомлення розмови, відсортовані за спаданням дати (`createdAt` desc для `inverted FlatList`), з даними відправника.
  - `sendMessage`: додає повідомлення, валідує авторство/участь, оновлює `lastMessage` та `lastMessageAt` у `conversations`.
  - `generateUploadUrl`: генерує одноразовий URL для завантаження фото в Convex Storage.

## 3. Екрани та користувацький інтерфейс (Expo Router)

### 3.1. Точки входу:
1. **Головний екран `app/(tabs)/index.tsx`**:
   - Іконка повідомлень у хедері праворуч: `router.push("/messages")`.
2. **Профіль іншого користувача `app/user/[id].tsx`**:
   - Кнопка «Повідомлення» поруч з кнопкою «Стежити»: відкриває або створює діалог з цим користувачем.

### 3.2. Нові екрани:
1. **`app/messages/index.tsx`**:
   - Список усіх активних чатів (`FlatList`).
   - Кнопка повернення назад та кнопка `+` для створення нового чату/групи.
   - Відображення аватарок, імен, останнього повідомлення та часу.
2. **`app/messages/new.tsx`**:
   - Вибір типу: особистий чат чи група.
   - Пошук / вибір користувача для особистого діалогу.
   - Поле назви групи та множинний вибір учасників для створення групового чату.
3. **`app/messages/[id].tsx`**:
   - Екран кімнати чату.
   - Хедер з даними співрозмовника / групи.
   - `FlatList` з `inverted={true}` для плавної стрічки повідомлень.
   - `KeyboardAvoidingView` для коректної поведінки при відкритті клавіатури на iOS та Android.
   - Нижня панель введення повідомлень з підтримкою прикріплення фото (`ChatInput`).

### 3.3. Компоненти:
- `components/MessageBubble.tsx`: бульбашка повідомлення (моє — праворуч `bg-primary`, чуже — ліворуч `bg-surface`), ім'я автора в групах, прикріплене фото, час відправки.
- `components/ChatInput.tsx`: інпут, вибір зображення, прев'ю обраного фото, кнопка відправки.
